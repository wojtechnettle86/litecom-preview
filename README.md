# Litecom — návrh webu

Statický návrh webu Litecomu pro veřejnou prezentaci na GitHub Pages.

## Zveřejnění

1. Vytvořte na GitHubu nový veřejný repozitář `litecom-preview`.
2. Přes Add file → Upload files nahrajte obsah této složky přímo do kořene repozitáře. Zachovejte podsložku assets. Nenahrávejte ZIP jako jeden soubor.
3. Potvrďte nahrání pomocí Commit changes.
4. V Settings → Pages nastavte Source na Deploy from a branch, větev main a složku / (root). Uložte.
5. Po dokončení nasazení se adresa zobrazí na stejné stránce.

Repozitář obsahuje pouze web a optimalizované obrázky. Neobsahuje původní dokumenty ani zdrojová videa.

Reference jsou návrhová místa. Kontaktní formulář nic neodesílá. Náhledy videí čekají na veřejně dostupné optimalizované verze. Fotografie a logo jsou materiály Litecomu; zveřejnění zdrojů neznamená udělení licence k jejich dalšímu použití.
